# Трекер расходов

Личный учёт расходов и доходов в виде веб-приложения (PWA), которое ставится на экран «Домой» айфона и работает как обычное приложение — в том числе без интернета.

- **Без сервера и регистрации.** Все данные хранятся только на телефоне (IndexedDB — встроенная база браузера).
- **Бесплатный хостинг** на GitHub Pages, деплой автоматический при каждом изменении в `main`.
- **Только рубли**, суммы с копейками.

## Возможности

- Расходы и доходы: сумма, категория, дата, комментарий. Правка и удаление (с кнопкой «Вернуть»).
- Список по дням с итогами, переключение месяцев, фильтр по категории.
- Статистика: итоги месяца, сравнение с тем же периодом прошлого месяца, средний расход в день, разбивка по категориям, график по дням, график и таблица за 6 месяцев.
- Регулярные платежи (подписки, аренда, зарплата): раз в месяц или раз в год. Записываются в операции сами, когда открываешь приложение; пропущенные дни догоняются, дублей не бывает.
- Свои категории с эмодзи.
- Резервная копия в JSON и восстановление из неё, выгрузка в CSV для Excel / Numbers.
- Светлая и тёмная тема (по настройке айфона), офлайн-режим.

## Запуск на GitHub Pages (один раз)

1. Репозиторий должен быть **публичным** — на бесплатном тарифе GitHub Pages работает только для публичных репо. Публичен только код; твои расходы в репозиторий не попадают.
2. Открой **Settings → Pages** и в поле **Source** выбери **GitHub Actions**.
3. Влей изменения в ветку `main` (или запусти вручную: **Actions → Tests & Deploy → Run workflow**).
4. Дождись зелёной галочки во вкладке **Actions** (1–2 минуты).
5. Сайт будет доступен по адресу: **https://ermin372.github.io/treker_rashodov/**

Если деплой упал на шаге `configure-pages` — значит, не сделан пункт 2.

## Установка на айфон

1. Открой ссылку выше **в Safari** (не в Chrome и не во встроенном браузере Telegram).
2. Нажми «Поделиться» (квадрат со стрелкой вверх) → **«На экран „Домой“»** → «Добавить».
3. Запускай приложение только с иконки.

> ⚠️ У Safari и у приложения с экрана «Домой» **разные хранилища**. Расходы, добавленные в Safari, не появятся в установленном приложении, и наоборот.

## Резервные копии — важно

Данные живут только на одном телефоне. Если удалить иконку с экрана «Домой», сбросить айфон или очистить данные сайтов — данные пропадут.

- **Настройки → Сохранить резервную копию** — откроется меню «Поделиться», сохрани файл в «Файлы» / iCloud Drive или отправь себе.
- Приложение само напомнит, если копии не было больше месяца.
- **Настройки → Восстановить из копии** — заменяет текущие данные данными из файла (так же переносятся данные на новый телефон).

## Обновления

После каждого деплоя в `main` приложение на айфоне обновится само при следующем запуске с интернетом (иногда нужно открыть его дважды). Версия сборки видна внизу экрана «Настройки».

## Локальная разработка

```bash
# запустить локально (без офлайн-кэша, чтобы правки сразу были видны)
python3 -m http.server 8080 -d app
# открыть http://localhost:8080

# тесты логики (деньги, даты, регулярные платежи, агрегаты, CSV, бэкап)
npm test
```

Сборки нет — это чистые HTML/CSS/JS-модули без зависимостей.

```
app/
  index.html            разметка и мета-теги для iOS
  manifest.webmanifest  описание PWA (имя, иконки)
  sw.js                 service worker: офлайн-кэш
  css/style.css         стили, светлая и тёмная тема
  js/app.js             интерфейс
  js/logic.js           чистая логика (покрыта тестами)
  js/db.js              работа с IndexedDB
  js/charts.js          SVG-графики
  icons/                иконки приложения
tests/logic.test.js     тесты (node --test)
.github/workflows/pages.yml  тесты + деплой на GitHub Pages
```

## Ограничения

- Нет синхронизации между устройствами — только перенос через файл резервной копии.
- Только одна валюта (₽).
- Регулярные платежи записываются, когда приложение открыто: если не открывать его месяц, все пропущенные платежи появятся разом при следующем запуске.
